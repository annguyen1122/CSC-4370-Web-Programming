Purpose:
Personal website dedicated to listing small personal projects I've done (e.g. indie games), go into detail on my obsessive interests in various medias, or any other type of information that I'd want to share. It's a site for anyone who's interested or curious about me, and a place for me to pour my mind into whatever I'd like.

Motive:
The biggest motivator behind creating this website is having a dedicated location for viewers interested in finding more of my projects, or interested in myself. I'm hoping to build my skills in web development as well for the future, as I'd want to create some useful applications in the future. I've planned out a couple of concepts for applications related to the interests that I have, although they're a bit too complex for my skill level at the moment. So as with all skills, I'll need to start from the beginning and learn the basics before I can begin with those ambitious personal projects. Along with that, I wanted to experiment with how to implement web games into a website as well since I have a previous game project that supports exporting in HTML5.
